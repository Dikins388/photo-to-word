# Фото → Word: восстановление документа по фото или скану

**Сайт:** https://dikins388.github.io/photo-to-word/

Бесплатный онлайн-сервис без регистрации. Он превращает фото или скан листа в редактируемый документ Word (.docx).
Бланк, логотипы и рисунки остаются фоном, как на оригинале. Весь текст стоит на тех же местах,
тем же шрифтом и размером, и при этом редактируется. Таблицы восстанавливаются с объединёнными ячейками.

*Українською:* безкоштовний сервіс без реєстрації відновлює документ з фото або скану в редагований Word (.docx):
бланк і малюнки залишаються фоном, текст стоїть на тих самих місцях і редагується.

## Как это работает

- **Распознавание прямо в браузере** ([Tesseract](https://github.com/tesseract-ocr/tesseract), украинский, русский
  и английский). Фото никуда не загружаются, поэтому сервер и ключи не нужны, а пользоваться им можно
  и для медицинских, и для личных документов.
- **Разбор страницы** собственным кодом:
  - колонки и блоки по координатам слов;
  - таблицы по линиям сетки, включая объединённые ячейки;
  - жирный по толщине штриха;
  - шрифт с засечками или без;
  - выравнивание наклона;
  - цветные надписи логотипов остаются частью фона.
- **Сомнительные слова** подсвечиваются жёлтым. В режиме сравнения оригинал и результат стоят рядом.
- **Экспорт .docx** делается в браузере: каждый блок текста становится рамкой на своём месте страницы, бланк кладётся фоном.
- **Режим Claude AI** (по желанию, со своим ключом API Anthropic) нужен для сложных фото.

Лучше всего результат на ровных сканах и фото, снятых строго сверху при хорошем свете.

## Реклама

Рекламные места: баннер сверху, блок в левой панели и баннер под документом. Код рекламы
вставляется в файл **`ads.js`**, больше ничего менять не нужно. Пока код не вставлен, на этих местах показывается
заглушка «Здесь может быть ваша реклама».

Google AdSense не принимает сайты на адресах вида `*.github.io`, ему нужен собственный домен.
GitHub Pages поддерживает свой домен бесплатно (Settings → Pages → Custom domain).

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | интерфейс, раскладка, редактор, сравнение |
| `ocr.js` | бесплатное распознавание и разбор страницы |
| `builder.js` | сборка .docx |
| `chart.js` | перерисовка графиков (режим Claude AI) |
| `ads.js` | рекламные места |
| `tess/` | движок Tesseract (tesseract.js, Apache-2.0) и языковые данные (Apache-2.0) |
| `docx.iife.js` | библиотека [docx](https://github.com/dolanmiu/docx) (MIT) |
